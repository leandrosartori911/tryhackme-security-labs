# Nmap - Network Enumeration

Room completed on TryHackMe.

## Overview

This module introduced the fundamentals of network enumeration using Nmap, one of the most important tools in penetration testing and cybersecurity.

Through practical exercises, I learned how to scan networks, identify open ports, detect services, and understand how firewalls interact with network scanning techniques.

## Skills Learned

- Network Enumeration
- Port Scanning
- Service Detection
- Firewall Evasion Basics
- TCP vs UDP vs SYN Scanning
- Nmap Command Usage
- Network Reconnaissance
- Understanding Open, Closed, and Filtered Ports

## Tools Used

- Nmap

## Concepts Learned

- Difference between TCP  UDP SYN scanning
- How Nmap interacts with firewalls
- Importance of enumeration during penetration testing
- Identifying running services on a host
- Basic reconnaissance techniques
